# 명찰 v0.3 기반 디자인 토큰

## 분석 기준

첨부된 명찰 v0.3 앞·뒷면 인쇄용 PDF와 실제 로고 PNG를 구현 전에 확인했습니다. 앞면은 95 × 125 mm 세로 비율, 넓은 흰 여백, 중앙 정렬된 제목, 얇은 구분선, 날짜·장소 정보, 딥 네이비 주최 띠의 계층이 뚜렷합니다. 뒷면은 연보라와 아이스 블루 면을 번갈아 쓰는 고밀도 3일 일정표입니다.

웹은 이 시각 언어를 복제 가능한 토큰으로 옮기되, 명찰의 작은 인쇄 글자를 그대로 가져오지 않고 휴대전화 가독성과 터치 영역을 우선했습니다. 기존 `nextbridge-classroom-kit` 안내 페이지의 스타일은 사용하지 않았습니다.

## 색상

| 토큰                  | 값        | 용도                            |
| --------------------- | --------- | ------------------------------- |
| `--color-navy`        | `#0A1E38` | 헤더 계층, 주최 띠, 어두운 배경 |
| `--color-navy-2`      | `#102846` | 네이비 보조 면                  |
| `--color-ink`         | `#111821` | 일반 본문과 제목                |
| `--color-blue`        | `#275DA8` | 명찰 상단 레일, 링크, 핵심 동작 |
| `--color-purple`      | `#5B4C93` | 절제된 브랜드 강조, 상태 강조   |
| `--color-purple-soft` | `#F1EDF8` | 일정·공지의 안정적인 밝은 카드  |
| `--color-ice`         | `#EAF2FA` | 보조 카드와 선택 상태           |
| `--color-line`        | `#D8DCE3` | 명찰식 얇은 테두리와 구분선     |
| `--color-muted`       | `#536172` | 흰색·연보라 배경의 보조 문구    |
| `--color-paper`       | `#FFFFFF` | 본문 카드                       |
| `--color-canvas`      | `#F7F7F5` | 전체 밝은 배경                  |

일반 텍스트 조합은 테스트에서 WCAG AA 4.5:1 이상인지 계산합니다. 네이비 배경의 흰색·연회색, 흰색 배경의 잉크·뮤트·블루·퍼플, 연보라 배경의 뮤트 조합이 대상입니다. 색만으로 상태를 구분하지 않고 라벨과 텍스트를 함께 제공합니다.

## 형태·간격

- 상·하단 브랜드 레일: 명찰과 같은 5px 시각 기준
- 테두리: 밝은 카드에 `1px solid #D8DCE3`
- 라운드: 작은 제어 10px, 카드 16px, 주요 패널 24px
- 간격 기준: 4, 8, 12, 16, 20, 24, 32, 40, 52, 64px
- 최대 본문 폭: 1160px
- 최소 터치 영역: 48px
- 카드 그림자: `0 18px 48px rgba(10, 30, 56, 0.10)`

정보 카드 뒤는 흰색·연보라·아이스 블루처럼 안정적인 밝은 면을 유지합니다. 배경 원형 장식은 본문과 분리하고 포인터 이벤트를 받지 않으며, `prefers-reduced-motion`에서는 움직임을 제거합니다.

## 서체와 위계

명찰 원본의 Pretendard를 우선하고, 기기에 없을 때 `Noto Sans KR`, `Apple SD Gothic Neo`, 시스템 산세리프로 폴백합니다. 별도 웹폰트를 내려받지 않아 첫 화면 성능과 개인정보 노출을 줄입니다.

- 행사명: 굵은 800–900, `clamp()`로 모바일/데스크톱 확장
- 섹션 제목: 750–850, 짧고 명확한 문장
- 본문: 최소 16px 수준과 여유 있는 행간
- 영문 eyebrow: 대문자·굵은 글자·넓은 자간으로 명찰의 작은 영문 표식만 차용
- 시간과 접수번호: 숫자 판독을 위해 굵기와 자간을 확보

## 로고 원칙

헤더와 푸터에는 제공된 심벌 원본을 비율 변경 없이 사용합니다. 행사 주최 표기에는 “경기도교육청” 텍스트와 제공된 로고를 함께 배치합니다. 로고 파일은 재채색하거나 웹 번들 안에 비밀정보를 포함하지 않습니다.

## 반응형·접근성 원칙

- 900px 이하에서 데스크톱 내비게이션을 하단 4개 메뉴로 전환
- 640px 이하에서 그리드·일정 행을 단일 열로 전환
- 360px에서도 `minmax(0, …)`, 줄바꿈, `max-width: 100%`로 가로 넘침 방지
- 키보드 skip link와 `:focus-visible` 3px 외곽선 제공
- 의미 있는 이미지에는 대체 텍스트, 장식 로고에는 빈 대체 텍스트 적용
- JavaScript 실패 시 일정·서명·이동 정보는 서버 렌더링 HTML로 유지
