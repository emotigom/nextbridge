# 2026 경기 성취평가 행사물 기반 디자인 토큰

## 분석 기준

2026 경기 성취평가 행사물의 제목 위계와 주요 색상을 웹의 기준으로 사용합니다. 첫 화면은 `경기 성취평가`를 가장 크게, `표준화 평가도구 개발`을 두 번째로, `합숙 워크숍`을 가장 작게 표시합니다.

이번 단계에서는 행사물의 물결, 외곽선, 인물·기관명 영역 등 도형과 그림을 복제하지 않습니다. 흰 여백, 텍스트 위계, 청록·파랑·민트 색상만 적용하며 휴대전화 가독성과 터치 영역을 우선합니다.

## 색상

| 토큰                  | 값        | 용도                  |
| --------------------- | --------- | --------------------- |
| `--color-navy`        | `#064F4B` | 어두운 청록 제목·배경 |
| `--color-navy-2`      | `#0A6F69` | 어두운 청록 보조 면   |
| `--color-ink`         | `#0C1212` | 일반 본문과 제목      |
| `--color-blue`        | `#0C4B96` | 부제, 링크, 핵심 동작 |
| `--color-purple`      | `#0B817A` | 행사물의 주 청록색    |
| `--color-purple-soft` | `#E7F4F1` | 청록색 밝은 카드      |
| `--color-ice`         | `#EEF8F6` | 선택 상태와 보조 카드 |
| `--color-mint`        | `#BDE5DD` | 밝은 민트 강조        |
| `--color-mint-strong` | `#86CCBD` | 진한 민트 강조        |
| `--color-line`        | `#CFE2DF` | 카드 테두리와 구분선  |
| `--color-muted`       | `#415C5A` | 보조 문구             |
| `--color-paper`       | `#FDFEFE` | 본문 카드             |
| `--color-canvas`      | `#F7FBFA` | 전체 배경             |

일반 텍스트 조합은 테스트에서 WCAG AA 4.5:1 이상인지 계산합니다. 흰색 배경의 잉크·보조색·파랑·청록, 어두운 청록 배경의 흰색·민트 조합이 대상입니다. 색만으로 상태를 구분하지 않고 라벨과 텍스트를 함께 제공합니다.

## 형태·간격

- 상단 색상 레일: 5px
- 테두리: 밝은 카드에 `1px solid #CFE2DF`
- 라운드: 작은 제어 10px, 카드 16px, 주요 패널 24px
- 간격 기준: 4, 8, 12, 16, 20, 24, 32, 40, 52, 64px
- 최대 본문 폭: 1160px
- 최소 터치 영역: 48px
- 카드 그림자: `0 18px 48px rgba(6, 79, 75, 0.09)`

정보 카드 뒤는 흰색·밝은 청록·민트처럼 안정적인 밝은 면을 유지합니다. 행사물의 장식 도형과 그림은 별도 승인 전까지 웹에 추가하지 않습니다.

## 서체와 위계

명찰 원본의 Pretendard를 우선하고, 기기에 없을 때 `Noto Sans KR`, `Apple SD Gothic Neo`, 시스템 산세리프로 폴백합니다. 별도 웹폰트를 내려받지 않아 첫 화면 성능과 개인정보 노출을 줄입니다.

- `경기 성취평가`: 가장 큰 900 굵기
- `표준화 평가도구 개발`: 두 번째 크기, 파랑 850 굵기
- `합숙 워크숍`: 가장 작은 보조 표기, 파랑 750 굵기
- 섹션 제목: 750–850, 짧고 명확한 문장
- 본문: 최소 16px 수준과 여유 있는 행간
- 시간과 접수번호: 숫자 판독을 위해 굵기와 자간을 확보

## 로고 원칙

헤더와 푸터에는 기존 심벌 원본을 비율 변경 없이 사용합니다. 첫 화면에는 행사물의 추가 그림이나 인물·기관명 도형을 넣지 않습니다. 로고 파일은 재채색하거나 웹 번들 안에 비밀정보를 포함하지 않습니다.

## 반응형·접근성 원칙

- 900px 이하에서 데스크톱 내비게이션을 하단 4개 메뉴로 전환
- 640px 이하에서 그리드·일정 행을 단일 열로 전환
- 360px에서도 `minmax(0, …)`, 줄바꿈, `max-width: 100%`로 가로 넘침 방지
- 키보드 skip link와 `:focus-visible` 3px 외곽선 제공
- 의미 있는 이미지에는 대체 텍스트, 장식 로고에는 빈 대체 텍스트 적용
- JavaScript 실패 시 일정·서명·이동 정보는 서버 렌더링 HTML로 유지
